Praecentor documentation
========================

Praecentor is a local rehearsal and performance tool for generating timing-aware
video guides from YAML song definitions. It is designed for the pianist-led,
rehearsal-focused workflow that needs a backing track, lyric display, chord and
riff prompts, and a beat grid that keeps the performance locked to the music.

The project combines:

- YAML song authoring
- tap-based lyric and beat timing capture
- validation and diagnosis tools
- render pipelines for multiple output variants
- optional layout overrides for presentation and styling
